ÖNERİLEN

Yerel üretim

Şablon tabanlı Türkçe senaryo, yerel seslendirme, FFmpeg ile video ve altyazı. API anahtarı veya abonelik gerekmez.

Haber RSS kaynaklarına internet bağlantısı gerekir.
İSTEĞE BAĞLI

Yerel yapay zekâ

Ollama ile bilgisayarında çalışan bir modeli kullan. Senaryonu geliştir; kullanım başına API ücreti ödeme.

OLLAMA_BASE_URL · OLLAMA_MODEL

Ollama ve seçtiğin modelin Mac'inde ayrıca kurulu olması gerekir. Modelin donanım gereksinimlerini kontrol et.

İSTEĞE BAĞLI

ElevenLabs

Kendi API anahtarını ekleyerek alternatif seslendirme kullanabilirsin. Ücretsiz kota sınırlıdır; ücretli kullanım doğabilir.

ELEVENLABS_API_KEY
ELEVENLABS_VOICE_ID

Varsayılan olarak kapalıdır. Video oluştururken açıkça seçmen gerekir.

İSTEĞE BAĞLI

OpenAI ve Claude

API ile senaryo oluşturma isteğe bağlıdır. ChatGPT Plus/Pro ve Claude Pro abonelikleri API kullanımını kapsamaz.

OPENAI_API_KEY · ANTHROPIC_API_KEY

Hesap oturumları burada kullanılmaz. API kullanımı ayrıca ücretlendirilebilir; ücretsiz şablon modu her zaman kullanılabilir.

YouTube bağlantısı

Hesabını yetkilendir, videonu önizle ve onayınla yükle. İlk yükleme varsayılan olarak gizlidir.

YOUTUBE_CLIENT_ID · YOUTUBE_CLIENT_SECRET

API anahtarlarını tarayıcıya yazma. Gerekli değişkenleri Mac'indeki .env dosyasında yapılandır; anahtarlar sunucu tarafında kalır.
